# Developer Portfolio

This is a professional developer portfolio website showcasing career journey and detailed resume.

## Pages

- **index.html** - Home page with professional introduction and navigation
- **career.html** - Comprehensive career journey and resume page with:
  - Professional Summary
  - Technical Skills
  - Professional Experience
  - Education
  - Certifications
  - Projects & Achievements

## How to View

Simply open `index.html` in a web browser, or serve the files using any web server:

```bash
# Using Python
python3 -m http.server 8080

# Using Node.js (http-server)
npx http-server

# Using PHP
php -S localhost:8080
```

Then navigate to `http://localhost:8080` in your browser.

## Features

- Responsive design that works on mobile and desktop
- Professional styling with modern gradient effects
- Easy navigation between pages
- Clean, organized resume layout
- No build process required - pure HTML/CSS
